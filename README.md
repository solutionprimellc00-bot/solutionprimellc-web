# solutionprimellc.com

Web de Solution Prime LLC: Spliup, Golden Trays y saxofón en vivo (español en `/`, inglés en `/en/`).

- Todo lo que se publica está en `public/`. Render la sirve como sitio estático (Publish directory: `public`, sin comando de build).
- Los textos de las dos páginas están en `construir.py` (diccionario `TEXTOS`). Para cambiar un texto: edítalo ahí y corre `python construir.py`; reescribe `public/index.html`, `public/en/index.html` y `public/404.html`.
- Fotos de las bandejas: de goldentrays.com. Foto del saxofón: cuadro del reel de saxofón de Joel. Logo de Spliup: el de oro, tal cual.
- Letras: Marcellus y Hanken Grotesk (licencia SIL OFL, en `public/fuentes/`).
